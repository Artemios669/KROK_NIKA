# НИКЕР — MVP подбора питомца

Демонстрационное веб-приложение для бережного подбора животного: диалог, лента карточек, детерминированный алгоритм совпадений, профиль животного, заявка и демо-панель.

## Запуск

Нужны Node.js 20+ и pnpm. В папке проекта выполните:

```bash
pnpm install
pnpm dev
```

Откройте `http://localhost:3000`. Проверка алгоритма: `pnpm test`. Сборка: `pnpm build`.

## Режимы

Без `.env.local` приложение целиком работает в явно обозначенном демонстрационном режиме; карточки и ответы чата — тестовые. Скопируйте `.env.example` в `.env.local`. Никогда не передавайте `OPENAI_API_KEY` в браузер и не публикуйте его в репозитории.

## Supabase

1. Создайте проект в Supabase.
2. Откройте SQL Editor и примените `supabase/migrations/001_initial.sql`.
3. Добавьте URL и anon key в `.env.local`.
4. Перед production настройте RLS-политики и серверный административный доступ. Тестовые записи из `lib/demo-data.ts` можно перенести в таблицу `animals`, заменив их проверенными данными приюта.

## OpenAI

Укажите `OPENAI_API_KEY` и `OPENAI_MODEL` на сервере. При наличии ключа чат использует официальный Responses API, Structured Outputs и Zod-проверку профиля; ключ никогда не передаётся в браузер. Без ключа он автоматически переключается на явно обозначенный детерминированный demo-режим. Сервер также ограничивает частоту сообщений: до 10 запросов в минуту на IP.

## Vercel

Импортируйте репозиторий в Vercel, добавьте переменные окружения из `.env.example` в настройках проекта и выполните Deploy. Миграции Supabase применяются отдельно в SQL Editor или CI.

## Структура

`app/` — страницы и API, `lib/matching/` — алгоритм, `types/` — модели, `supabase/migrations/` — SQL, `tests/` — сценарии алгоритма. Код намеренно компактный и снабжён ясно выделенными demo-данными, чтобы его было удобно развивать начинающим разработчикам.
