# НИКЕР — MVP подбора питомца

Демонстрационное веб-приложение для бережного подбора животного: диалог, свайпы по анонимным характеристикам (до 10 карточек), детерминированный алгоритм совпадений, профиль животного, заявка и демо-панель.

## Запуск

Нужны Node.js 20+ и pnpm. В папке проекта выполните:

```bash
pnpm install
pnpm dev
```

Откройте `http://localhost:3000`. Проверка алгоритма: `pnpm test`. Сборка: `pnpm build`.

## Режимы

Без действующего ключа приложение работает в демонстрационном режиме; карточки и ответы чата — тестовые.

## Gemini API (бесплатная квота)

Чат уже подключён к Gemini через серверный маршрут `/api/chat`. Для запуска с ИИ:

1. Откройте [Google AI Studio](https://aistudio.google.com/app/apikey), войдите в Google и создайте API key.
2. В корне проекта скопируйте `.env.example` в `.env.local`, если такого файла ещё нет.
3. В `.env.local` укажите ключ и модель:

   ```dotenv
   GEMINI_API_KEY=вставьте_сюда_свой_ключ
   GEMINI_MODEL=gemini-3.5-flash-lite
   ```

4. Сохраните файл, перезапустите `pnpm dev` и откройте `http://localhost:3000/chat`. Убедитесь, что в чате отображается «GEMINI-ПОМОЩНИК».

Ключ используется только на сервере и не должен попадать в браузер, Git или сообщения. Не отправляйте его другим людям. Если ключ уже задан, но запрос не работает, создайте новый в AI Studio и замените значение в `.env.local`; после изменения перезапустите сервер. Бесплатная квота ограничена и зависит от доступности модели, региона и условий Google. При исчерпании квоты подождите её восстановления; не подключайте платный биллинг, если не хотите расходов. Без ключа приложение остаётся доступно в демонстрационном режиме. Переменные `OPENAI_API_KEY` и `OPENAI_MODEL` для текущего чата не нужны.

## Supabase

1. Создайте проект в Supabase.
2. Откройте SQL Editor и примените `supabase/migrations/001_initial.sql`, затем `supabase/migrations/002_animal_characteristics.sql`.
3. Добавьте URL и anon key в `.env.local`.
4. Перед production настройте RLS-политики и серверный административный доступ. Тестовые записи из `lib/demo-data.ts` можно перенести в таблицу `animals`, заменив их проверенными данными приюта.

Дополнительные карточки характеристик берут сведения из `coat_details`, `ear_shape`, `shelter_story`, `health_notes` и `interesting_facts`. Эти поля необязательны: если приют не подтвердил факт, оставьте его пустым — он не появится в свайпах.

## Vercel

Импортируйте репозиторий в Vercel, добавьте переменные окружения из `.env.example` в настройках проекта и выполните Deploy. Миграции Supabase применяются отдельно в SQL Editor или CI.

## Структура

`app/` — страницы и API, `lib/matching/` — алгоритм, `types/` — модели, `supabase/migrations/` — SQL, `tests/` — сценарии алгоритма. Код намеренно компактный и снабжён ясно выделенными demo-данными, чтобы его было удобно развивать начинающим разработчикам.
